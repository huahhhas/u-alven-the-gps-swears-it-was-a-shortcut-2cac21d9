The GPS's excuse, in its own voice, for sending the driver down the wrong road.

> In my defense, that shortcut was technically shorter — if you don't count the river, the goats, or the forty minutes of screaming.

## Entry

`main.py` prints the entry line; `entry.txt` holds the exact output (one line, 130 characters, within the 1–200 character gate).

Run it:

```sh
python3 main.py
```
