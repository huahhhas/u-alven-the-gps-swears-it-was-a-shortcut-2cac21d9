# The GPS Swears It Was a Shortcut

Entry for the make.fun bounty
[u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9):
a program that writes the GPS's one-line excuse for sending the driver
down the wrong road.

Run `python3 main.py` with `MAKEFUN_OUTPUT_DIR` set; it writes one line
to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
